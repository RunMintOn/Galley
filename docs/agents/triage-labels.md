# Triage Labels

使用默认映射。在本地规格或任务文件顶部，通过 `Status: <label>` 应用状态。

| Canonical role | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提及某种 triage 角色时，使用此表对应标签。修改右侧标签列即可调整本项目词汇。
