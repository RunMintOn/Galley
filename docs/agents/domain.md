# Domain Docs

本项目使用 single-context 布局。

## 探索前阅读

- 根目录 `GLOSSARY.md`：统一领域术语。
- `docs/adr/`：阅读与当前改动相关的架构决定。

文件不存在时直接继续，不为缺失发出提醒，也不提前创建占位文档。术语或架构决定需要记录时，通过 `/domain-modeling` 按需创建。

## 文件布局

- `GLOSSARY.md`：项目级术语表。
- `docs/adr/NNNN-<decision>.md`：项目级架构决定。

## 使用领域词汇

规格、任务、测试名称及其他输出使用术语表中已有的定义，避免另起同义词。需要的概念未定义时，先判断是否确有必要；真实缺口留待 `/domain-modeling` 处理。

## ADR 冲突

方案与已有 ADR 冲突时，明确指出冲突及重新讨论的理由，不静默覆盖。
