# 日用文件树

## 已确认范围

- Review、Git 文件树统一竖线、缩进、行高、图标和选中样式。
- 修复回到应用时项目列表跳动，保留列表位置。
- 文件树支持新建文件/目录、重命名、复制/剪切/粘贴、副本、废纸篓、复制两种路径、Finder/默认应用/终端打开。
- 新建和重命名使用树内输入；新文件直接编辑。文件行的新建位置为同级，目录行为其内部，空白为项目根目录。
- 文件复制粘贴仅限 Galley 内，支持跨已添加项目。快捷键只在文件树获得焦点时处理文件。
- Review/Git 改动及历史文件菜单只提供路径和定位/打开当前文件，不修改历史文件。
- ⌘P 按文件名和路径快速查找当前项目，沿用文件树排除规则。
- 定位当前文件、全部折叠、按项目记忆目录展开状态，记忆各栏折叠状态。
- 折叠后整条竖栏可点击展开，顶部图标保持原位；项目操作菜单不越过窗口左边界。
- 三处目录树去掉独立展开箭头，整行切换展开状态；保留目录图标、文件类型配色与层级竖线。
- 成功操作有通知，文件操作带撤回。普通操作不反复确认；草稿和同名冲突需要处理。
- 撤回限本次运行最近一次；文件已被修改时不覆盖。重命名/移动保留当前草稿，复制使用磁盘版本。

## 完成标准

- 可通过树、右键及键盘完成新建、复制、移动、重命名和撤回。
- 同名不覆盖，撤回不丢失后续修改，草稿跟随路径。
- 搜索能找到未展开目录下的文件，展开和栏折叠在刷新后恢复。
- 做相关文件操作和隔离浏览器快检，重建正式桌面包。

## 不做

永久删除、完整文件操作历史、Finder 文件剪贴板互通、全文搜索、多选、拖拽移动。
