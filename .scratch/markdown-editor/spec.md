# Markdown 文件编辑与界面整理

保留审查台，将临时文档升级为独立文件编辑窗口。用户已确认实施。

## 验收
- 原生打开、多文件标签、Cmd+S、首次保存对话框、另存为；修改标记与关闭时保存/不保存/取消。
- Finder 打开方式与 Markdown 文件类型关联，不自动改变系统默认应用。
- 剪贴板图片先暂存预览，保存时写入 `<文件名>.assets/`；已有 Markdown 的相对路径和远程图片能显示。
- 外部改动：干净文件自动刷新，脏文件提示且不静默覆盖。
- 源码查找替换；删除可见的 Markdown source 冗余标题。
- 审查台文件区支持源码/分栏/预览，不占用 Agent 回复区；共用“默认预览”偏好。
- 第三、四栏分界可拖动，记住宽度，兼容折叠和窄窗口。
- 编辑器参考用户提供的 Zed 截图，文件树参考 VS Code；统一中性分隔线、语法色与 SVG 图标。
- 关键行为自动测试；无头截图审视深浅主题与窄窗。不操作日用应用。

不包含独立图片查看器、图片编辑、云同步或插件系统。
