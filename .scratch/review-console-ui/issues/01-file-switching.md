# 01: 正常切换文件，准确保护草稿

**What to build:** 浏览文件时未改动不误提示；实际编辑、撤销、保存及外部变化后，切换和草稿保护符合用户预期。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 先复现并用浏览器行为测试验证未编辑时的异常提示；保留能防止回归的测试。
- [x] 未修改、编辑后完全撤销、正常保存后切换不误提示；文件原有换行不因浏览或保存而被无意改变。
- [x] 实际修改后取消切换保留草稿；保存请求期间及外部修改不丢草稿、不静默覆盖。
- [x] 类型检查和受影响测试通过，记录实际原因与验证结果。

## Comments

新增浏览器测试先失败：未编辑的 CRLF Markdown 切换时弹出“存在未保存修改”。原因是 CodeMirror 文档内部规范化换行后，与磁盘原文直接比较。现在按原文件换行格式序列化，浏览不会制造草稿，修改保存也保留换行。类型检查、构建及浏览器流程通过，包括完全撤销、保存期间继续编辑、真实草稿取消切换及外部冲突。
