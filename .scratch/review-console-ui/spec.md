## 回复原文

第三栏是共用内容区：文件、diff、Git 历史或当前回复的 Markdown 原文。点击第四栏的“源码”切换第三栏，不在第四栏另建原文编辑区。第四栏继续预览；原文临时编辑同步更新预览，不写盘、不回写会话。再次点击返回原先内容；需要保护原先文件草稿。第三栏收起时应展开，使切换结果可见。

未来 Markdown 多 Tab 编辑模式不在本轮实施。

## 验证与边界

沿用已确认的两个验证边界：隔离本地服务的公开 API 和真实隔离浏览器。对文件切换等问题先写会失败的行为测试再修复；截图分别对照 Paper 与原 VisualReply，不以测试命令通过替代视觉验收。

使用确定性项目、报告和回复样本，不调用模型 API，不接管 Agent，不改旧插件或日用 pi 配置。不引入框架或 iframe。原有手动保存、冲突保护、捕获范围、轮次配对和只读 Git 约束继续适用。
