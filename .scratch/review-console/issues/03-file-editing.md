# 03: 文件上下文与手动保存

**What to build:** 用户从树或回复进入完整文件，在同一审查台阅读并手动编辑。

**Blocked by:** 02：多项目、多会话和轮次切换

**Status:** ready-for-agent

- [ ] 目录按需加载；文件访问限制于授权根，阻止路径与符号链接越界。
- [ ] Markdown 默认可编辑，代码默认只读，e 启用；Cmd+S 手动保存。
- [ ] 外部写入触发冲突，不静默覆盖；切换和关闭保护草稿。
- [ ] 文件链接支持明确路径和行号；大文件读取有上限及分段查看。
- [ ] 只监听前台活跃项目，失焦关闭监听，恢复后比对。
