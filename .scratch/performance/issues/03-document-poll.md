# 03: 减少多标签外部修改检查的桥接开销

2026-11-01 用户明确主界面编辑器优先、独立 Markdown 窗口不优先，本任务暂停实现。只保留摸排探针 `.scratch/performance/research/document-poll.mts`。20×256KiB 文件的真实桥接检查分别为 54/29/27ms，每次返回 5MiB 正文；尚未优化。

## 待验证

- 未变化文件仍通过桌面桥返回全文，可能使前台每两秒重复传输大量文本。
- focus、visibilitychange 和定时器可能启动重叠检查。
- 文件读取与 SHA-256 是否占主要耗时，需要和桥接传输区分测量。

## 验收

- [ ] 先记录真实 WKWebView 桥接的优化前数据，建立可失败的无变化全文传输回归。
- [ ] 只在内容改变时传回全文；保留内容哈希检测，不以 mtime/大小代替内容版本。
- [ ] 多标签检查合并，重叠触发不并发放大工作；保存、关闭或另存为后的旧结果不覆盖新状态。
- [ ] 未编辑文件自动刷新、有草稿时保留草稿并提示冲突，单个读取错误不阻断其他文件。
- [ ] 真实桌面桥对照、Go 和浏览器回归通过，更新文档和正式包后提交。
