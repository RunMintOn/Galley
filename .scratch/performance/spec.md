# 日用性能优化

用户授权自主寻找并优化收益大的性能问题，可占用桌面进行隔离测试。不调用模型、不迁移旧插件、不修改日用项目内容。

## 首批范围

1. Markdown 预览编辑时复用未变化的块，不重复高亮或重建未变化的图表。
2. 文件源码模式不计算隐藏预览；切回分栏或预览时显示最新草稿。
3. Git 工作区单文件详情不读取无关的未跟踪文件。

## 验收

- 有同一夹具、同一测量口径的优化前后结果，记录主线程耗时和 DOM 重建。
- Markdown 引用、脚注、列表、表格、代码、公式、图表与图片保持正确；修改图表或主题仍能刷新。
- 未变化图表在正文编辑后保留节点和交互状态，移除块时释放挂载资源。
- 源码模式编辑没有预览更新，切回后内容正确。
- 工作区保留 staged、unstaged、untracked 的比较语义、完整 Diff 和既有读取边界。
- 相关浏览器回归、公共接口测试、原生桌面验证通过；构建正式桌面包。

## 测量边界

合成文档只用于可复现对照，不代表所有日用内容；Chrome 与 WKWebView 的结果分开报告。时间预算不冒充硬件无关保证，不将 JavaScript heap 当成应用总内存。

## 已摸排的低优先级候选（暂停实现）

2026-11-01 用户明确：主要优化主界面编辑器，pi 集成和独立 Markdown 窗口不优先。以下两项只保留摸排与票据，不继续实现。

多标签外部修改检查：先区分磁盘读取/哈希、桥接全文传输和重复触发的成本，再减少无变化时的工作。保留基于内容哈希的冲突检测与草稿保护。独立验收见 `issues/03-document-poll.md`。

长会话状态更新：已知会话的忙闲变化不重新获取完整轮次元数据或重建轮次选择项，仍保留新轮次、注册和重连刷新。独立验收见 `issues/04-session-state.md`。

## 第二批范围

主界面的文件编辑器和 Diff：测量大文件打开、输入、脏状态判断，以及 Diff 首次渲染和 Unified/Split 切换。优先减少热路径上的全文处理和重复计算，不截断内容或改变保存、撤销语义。

## 第三批范围

用户反馈主界面 Git 长 Diff 往返滚动时分片补画、不跟手。区分接口/DOM 更新与 WebView 绘制成本，在真实 WKWebView 复现并做单变量对照；保留完整内容、语法高亮、折叠和原有滚动方式。独立验收见 `issues/06-diff-scroll.md`。
