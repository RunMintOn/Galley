# 08：独立多标签临时文档工作区

## Goal

实现 scratch 原型对应的独立工作区，提供 Markdown 编辑/预览与两段文本对比；可与四栏窗口共存。

## Scope

以 [spec.md](../spec.md) 为产品与数据契约来源。本票实现已完成；验收证据和未专项验证的边界见 Comments。

## Acceptance

- [x] 先写行为测试；提供明确的 Markdown / Diff 新建入口、标签关闭、重命名以及横向/纵向排列切换，不复制 Prototype 工具栏。
- [x] Markdown Source / Split / Preview 三态可切；复用渲染能力与纸色视觉，原始 HTML 继续关闭。后续按用户验收补齐公式、Mermaid、函数图，见 `review-console-polish` 票据。
- [x] Diff Edit 时两侧可编辑，Diff 时只读对照；复用 05 的配对规则，覆盖新增、删除、替换、不等长和空文本。
- [x] 切标签、布局、显示模式或窗口焦点保留文本；默认标题取首行标题或 untitled，手工命名后不再自动覆盖。
- [x] 非空标签关闭前确认，取消不丢内容；暴露窗口/应用退出所需的非空状态与确认动作，原生接线由 09 完成。
- [x] 内容只在内存，不写仓库、浏览器持久化存储、日志或恢复文件；确认关闭后丢弃，重新打开为空工作区。
- [x] 页面入口与四栏分离，不受审查台页面交接机制替换；两类界面使用共同视觉资源和可复用渲染职责，不复制两套独立实现。
- [x] 按钮和键盘操作对应同一用户动作；原生 Cmd+T/W/数字的最终验收在 09，不以网页合成事件冒充完成。

## Implementation Notes

网页部分沿用现有构建/浏览器驱动；实际窗口由 02/09 接入。临时内容“不保存”不等于切换标签就丢弃，也不扩展为自动保存、恢复或通用 IDE。
