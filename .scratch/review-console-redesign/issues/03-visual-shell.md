# 03：共享视觉令牌与四栏布局

## Goal

按原型刷新外观，形成两窗口可共用的视觉基础，统一应用主题而不抹掉独立纸色。

## Scope

以 [spec.md](../spec.md) 为产品与数据契约的唯一来源，尤其“执行边界与交付顺序”。本票未开始；当前仅授权文档准备，实施需用户另行授权。

## Acceptance

- [ ] 获准后实际点验两个原型；按 spec 区分可复用视觉值与假数据、演示控件。
- [ ] 系统无衬线用于界面，代码/路径/hash/数字用等宽；统计列对齐；中性背景、增删实色、无投影和内容纸面符合原型。
- [ ] 1440px 内容视口下完整四栏可用，回复栏至少 360px；记录窄窗口最小尺寸/折叠策略，导航折叠后主要操作可达。

- [ ] 使用现有视觉驱动保留深浅主题、纸色及窄窗口截图；只对可见可用性写行为断言，不以 CSS 类或圆角数值验收。
