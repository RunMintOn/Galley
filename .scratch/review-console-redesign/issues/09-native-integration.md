# 09：原生菜单、双窗口、关闭保护与 /review 唤回

## Goal

将两类完成的网页工作区接到 macOS 外壳，补齐真实窗口和原生快捷键生命周期。

## Scope

以 [spec.md](../spec.md) 为产品与数据契约的唯一来源，尤其“执行边界与交付顺序”。本票未开始；当前仅授权文档准备，实施需用户另行授权。

## Acceptance

- [ ] 审查台有可见入口打开/聚焦独立临时窗口，菜单也可操作；两窗口并存，切换焦点不重建或丢内容。
- [ ] 临时窗口 Cmd+T 新建 Markdown、Cmd+W 关闭当前标签、Cmd+1…9 切换；菜单按聚焦窗口派发，在审查窗口不执行临时标签命令。
- [ ] 保留 macOS 编辑菜单、剪贴板、撤销重做、IME 和当前文件 Cmd+S；主要项目/文件/轮次操作可通过键盘完成且编辑时不抢阅读按键。
- [ ] 原生窗口关闭与 Cmd+Q 检查真实文件草稿及非空临时内容；取消保留全部状态，确认后才丢弃，不仅依赖 beforeunload。
- [ ] /review 能启动已安装应用或唤回已有单实例，正确定位隔离会话；未保存文件阻止切换时保留草稿并明确提示。
- [ ] 应用退出后后台服务及捕获继续，重开不产生重复服务；重复启动、关最后窗口、Dock 再激活行为一致。
- [ ] 外链交给系统浏览器，应用页面不被任意外站导航替换；原生权限与服务凭证不向外部页面泄露。
- [ ] 真实 mygo / WKWebView 下保留菜单/按键/关闭取消/双窗口和会话唤回的可复现结果，桌面交互前取得许可。
