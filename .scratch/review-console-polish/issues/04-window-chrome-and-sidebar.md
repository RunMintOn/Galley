# 04: 合并窗口标题栏与侧栏细节

## 完成内容

- 主窗口与独立 Markdown 窗口使用隐藏式原生标题栏，保留红黄绿按钮，内容区顶部可拖动窗口；原生按钮位置为 `(12, 12)`。
- 主窗口不再显示独立的项目标题和省略号按钮，保留添加与收起。上移操作并入项目右键菜单，操作目标为右键项目；复用原有移除项目入口。
- 项目栏最小宽度保持 140px。折叠时单独为原生按钮留出横向空间，避免覆盖相邻栏。
- 侧栏列表使用覆盖式滚动条，不预留槽位；滚动时显示，停止 800ms 后隐藏，支持拖动。不以鼠标悬停作为常驻条件。
- 项目名、分支与路径固定左缩进 16px；工作状态圆点独立定位，直径 5px，与文字间隔 6px，不造成文字位移。
